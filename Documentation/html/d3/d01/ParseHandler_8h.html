Description détaillée

Fichier contenant les déclarations des fonctions de l'interface de la classe _ParseHandler_.

Un objet ParseHandler est un objet qui définir comment interpréter les différents caractères lus dans un objet de type _Parser_, il le fait par le biais d'une fonction que le parseur va appeller à chaque caractère lu.
Les objets _ParseHandler_ sont composés d'autres objets de type _ParseHandlerInterpret_ qui sont des objets permettant de définissant certains actions à faire lors de la rencontre de certains caractères.

En gros L'objet _ParseHandler_ va reconnaitre cetrains caractères "spéciaux" et _ParseHandlerInterpret_ va définir les actions à faire lorsqu'on rencontre ces caractères.


Cette classe est donc une classe abstraite qui doit être redéfinie sur des classes plus spécifiques dans leur interprétation de caractères.

Construction : obj_new(_ParseHandler_, ParseHandlerInterpret interpretor )
où :

  • _ParseHandler_ désigne la classe des objets de type ParseHandler
  • interpretor est un objet ParseHandlerInterpret qui va interpréter les différents caracètres "spéciaux" reconnu par l'objet ParseHandler.

Fonction qui interprète un caractère lu par le parseur.

Cette fonction va appeller une redéfinition (obligatoire sinon il y aura une erreur) de la fonction interpret(ParseHandler self, struct _Parser_* parser, char c) dans une classe fille.


C'est à la classe fille d'indiquer comment elle décide d'interpréter le caractère (si ce caractère est considéré comme spécial par exemple).

Paramètres
selfL'objet qui va gérer tous les caractères lu par le parseur.
parserLe parseur qui a lu le caractère (pour pouvoir lui demander de l'accepter par exemple).
cLe caractère lu par le parseur.
