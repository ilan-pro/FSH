Description détaillée

Fichier d'en-tête contenant les déclarations des variables publiques et de toutes les méthodes public de ExternalCommand.

ExternalCommand est la classe des commandes externes.

Construction : obj_new(ExternalCommand, "nom_de_la_commande_externe");
_ExternalCommand_ désigne la classe des commandes de type ExternalCommand (commandes externes). et la chaine "nom_de_la_commande_externe" doit contenir le nom de la commande.
