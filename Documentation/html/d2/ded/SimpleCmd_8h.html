Description détaillée

Fichier d'en-tête contenant les déclarations des variables publiques et de toutes les méthodes public de _SimpleCmd_.

Un objet de type _SimpleCmd_ est une commande dont les arguments et les paramètre sont récupéré directement (avec un parsing) dans le construteur. Ces commandes sont donc tous de la forme Cmd_name -param1 -param2 arg1 -parm3 .... Les arguments et les paramètres pouvant êtres déclarés dans un ordre quelconque et les paramètre peuvent être concaténés (Ex: cmd -AbCd = cmd -A -b -C -d).

Cette classe ne fourni pas de méthode execute(), elle doit donc être héritée par une classe qui implémentera la méthode sinon l'exécution déclanchera une erreur.

NB : Les commandes ayant une définition complexe comme les commandes avec des paramètres non-booléens (Ex : cmd --param=oiseau -param1 Wazo ou for i in ... {} ). Ne peuvent pas être construit directement avec le constructeur, alors il est conseillé d'hériter directement de la classe _Command_ au lieu de celle-ci et de définir un constructeur qui gère la construction de la commande.

Construction : obj_new( _SimpleCmd_, char* cmd_name, char** prompt ); où :


_SimpleCmd_ désigne la classe des objets de type SimpleCmd. char* cmd_name Le nom de la commande. char** prompt Le reste du prompt qui va servir à construire la comande.

Fonction qui vérifie si oui ou non le caractère actuellement pointé par le pointeur vers le prompte de l'utilisateur est valide, c'est à dire si on doit oui ou non arrêter la parsing de la commande.

Un caractère est valide si et seulement si :

  • Ce n'est pas le caracètre null (fin de chaine).
  • Ce n'est pas l'un des caracètres '|', ';' ou '}'.

Si le caractère n'est pas null (fin de chaine) et qu'il est entre guillemets (simple ou double) ou échapé alors il est autamatiquement valide ('|', ';' et '}' seront considérés comme des caracètres normaux).

Paramètres
quotedBooléen indiquant si le caracètre est entre guillemets simple.
double_quotedBooléen indiquant si le caracètre est entre guillemets doubles.
escBooléen indiquant si le caracètre est echapé par \ .
promptLe prompt en cours de paring.
Renvoie
Si oui ou non le caractère actuellement pointé par le pointeur vers le prompte de l'utilisateur est valide.
