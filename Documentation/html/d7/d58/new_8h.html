Description détaillée

Fichier d'en-tête contenant les déclarations de toutes les méthodes génériques agissant sur des objets.

Ce fichier contient les signatures publiques des fonctions générique agissant sur des objets, par exemple obj_new() qui est une fonction qui initialise un nouvel objet, à partir d'une classe.

Documentation des fonctions

◆ obj_clone()

void* obj_clone ( const void *  self_)

Fonction qui crée et renvoie la copie d'un objet.

La fonction appelle la fonction clone() définie dans la classe de l'objet et il est conseillé d'en avoir une.

Si la fonction n'est pas définie dans la classe alors cette fonction réalisera une copie bit à bit de l'espace mémoire dédié à l'objet, avec memcpy() ce qui peut être très risqué car si l'objet avait des références dans ses attributs (pointeurs vers d'autres objets) sa copie aura les mêmes références. Cela peut déclancher une erreur au moment de la destruction des objets car le destructeur va détruire deux fois la même réfénrence.

Paramètres
self_L'objet à cloner.
Renvoie
Une copie de l'objet.

◆ obj_destroy()

void obj_destroy ( void *  self_)

Fonction qui détruit et desalloue l'espace mémoire alloué pour l'objet.

La fonction va appeler la fonction dtor() définie dans la classe de l'objet, qui va désallouer tous les éléments utilisés dans l'objet, puis après l'appel, va désallouer l'objet avec free().

NB : La desallocation du pointeur vers l'objet self_ ne doit pas se faire dans dtor(), cela va générer une erreur car au retour de l'appel cette fonction le fait également (il y aura donc deux free() sur une référence)).

Paramètres
self_L'objet à détruire.
Exceptions
Abort.Le programme est interrompu si une fonction de destruction n'est pas définie dans la classe. Cela permet de garantir une destruction profonde de l'objet, évitant les fuites de mémoire.

const void *  object_

Fonction qui renvoie si oui ou non les deux objets sont egaux.

La fonction appelle la fonction equals() définie dans la classe de l'objet. Si la fonction n'est pas définie elle compare bit à bit les deux objets en mémoire. (avec la fonction memcmp())

Paramètres
self_L'objet 1.
object_L'objet 2.
Renvoie
Si oui (1) ou non (0) objet1 et objet2 sont égaux.

Fonction qui permet de vérifier si un objet est l'instance d'une classe donnée.

Cette fonction fonctionne également sur les objets dont la classe hérite d'une autre ( elle vérifie récursivement avec les ancètres).

Renvoie

◆ obj_new()

void* obj_new ( void *  _class_,
  ... 
)

Fonction qui crée un objet à partir de sa classe.

La fonction alloue dynamiquement la mémoire l'objet avec calloc(), et appelle le constructeur définie dans la classe (Liaison dynamique). Si un constructeur n'est pas définie alors la fonction obj_new() renvoie l'objet avec tous les attribut à 0 (à cause calloc()).

Paramètres
_class_La classe de l'objet à construire.
...La liste des arguments que prend le constructeur.
Renvoie
L'objet renvoyé par le constructeur définie dans sa classe ou la structure telle qu'elle a été alloué avec calloc() (si il n'y avait pas de constructeur).

◆ obj_print()

void obj_print ( const void *  self_)

Fonction qui affiche le contenu d'un objet.

La fonction appelle la fonction print() définie dans la classe de l'objet.

Si la fonction n'est pas définie dans la classe alors cette fonction affichera le résultat de l'appel à to_string() sur l'objet.

Paramètres
self_L'objet à afficher.

◆ obj_to_string()

char* obj_to_string ( const void *  self_)

Fonction qui renvoie une chaine de caractère représentative de l'objet.

La fonction appelle la fonction to_string() définie dans la classe de l'objet qui doit renvoyer une chaine de caractère.

Si la fonction n'est pas définie, obj_to_string() renvoie le nom de la classe suivi de l'adresse du pointeur de l'objet.

ATTENTION : NE JAMAIS RENVOYER UNE CHAINE DE CARACTERE ALLOUEE DYNAMIQUEMENT !
Il est impératif d'écrire directement dans le buffer to_string_buffer situé en dessous et de laisser au code appelant la responsabilité de décider s'il souhaite en faire une copie ou non.

Paramètres
self_L'objet à interroger.
Renvoie
La chaine de caractère renvoyé par to_string, qui est généralement un pointeur vers to_string_buffer ci-dessous.

◆ to_string_buffer

char to_string_buffer[1024]
extern

Mémoire tampon qui doit être utilisée dans les fonctions to_string des objets. Cette mémmoire est généralement statique, afin d'éviter les allocations dynamiques.

De cette façon on réduit les risques de fuites mémoire et on confie au code appelant la responsabilité de gérer, si nécessaire, une copie de la chaîne résultante.
