◆ Command_execute()

int Command_execute ( Command  self)

Fonction qui va exécuter la commande.

Cette fonction est abstraite (déclanche une erreur si aucune redéfinition n'est trouvée), à chaque appel la fonction va appeller la méthode execute() de l'objet (liason dynamique). Cela va permettre plus tard de créer une file de commandes toutes distinctes et de les éxécuter.

Paramètres
selfLa commande à faire exécuter.
Renvoie
La valeur de retour de la commande après exécution.

Class _Command_ = &__Command__

Classe de toutes les commandes.

Il s'agit d'une classe abstraite qui représente une commande interne du shell. Elle possède une méthode abstraite à redéfinir dans tout sous-type de commande (sinon cela va déclancher une erreur), qui la méthode execute() appelée par Command_execute(), la fonction appelée pour exécuter la commande.

Construction : obj_new(_Command_, <Nom_de_la_commande> )
