Description détaillée

Classe de toutes les commandes simples.

Un objet de type _SimpleCmd_ est une commande dont les arguments et les paramètre sont récupéré directement (avec un parsing) dans le construteur. Ces commandes sont donc tous de la forme Cmd_name -param1 -param2 arg1 -parm3 .... Les arguments et les paramètres pouvant êtres déclarés dans un ordre quelconque et les paramètre peuvent être concaténés (Ex: cmd -AbCd = cmd -A -b -C -d).

Construction : obj_new( _SimpleCmd_, char* cmd_name, char** prompt ); où :

  • _SimpleCmd_ désigne la classe des objets de type SimpleCmd.
  • char* cmd_name Le nom de la commande.
  • char** prompt Le reste du prompt qui va servir à construire la comande.
