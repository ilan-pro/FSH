Description détaillée

Classe String des chaines de caractères.

Il s'agit d'un boxing du type char* en object de type String.

Il permet nottement de les utiliser dans des structure de donnée génériques comme les listes.

Construction : obj_new( _String_, <chaine_de_caractere> );
