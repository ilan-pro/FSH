Description détaillée

Fichier d'en-tête contenant les déclarations des variables publiques et de toutes les méthodes public de la classe _If_.

La classe _If_ est une classe de commande permettant de contrôler l'exécution d'un bloc de commandes en l'exécutant sous une certaine condition (un ensemble de commande Test).

Construction obj_new( _If_, char** prompt ); où :

  • _If_ désigne de la classe des objets Command de type If.
  • char** prompt La suite du prompt (qui permet d'initialiser le reste de la commande).
