Description détaillée

Classe des objets de type CommandParseHandlerInterpret.

Un objet ParseHandlerInterpret est un objet qui possède un certain nombre de fonctions qui seront appelées par l'objet _ParseHandler_ qui le contient, ces fonctions doivent définir les différentes actions à faire au moment de la rencontre de certains caractères spéciaux reconnu par l'objet _ParseHandler_.

Cette classe est un sous-type qui définie des fonctions pour gérer les caractères spéciaux des commandes du shell tels que ';', '|', etc.

Cette classe a les méthodes public qui doivent toutes être redéfinies (mais ne déclanchent pas d'erreur si ce n'est pas le cas) elles ont une implémentation par défaut, qui d'accepte (ajoute le caractère au tampon du parser) tous les caractères spéciaux. Donc le mieux c'est de redéfinir celles dont on souhaite interpréter autrement.

où _CommandParseHandlerInterpret_ désigne la classe des objets de type ParseHandlerInterpret
