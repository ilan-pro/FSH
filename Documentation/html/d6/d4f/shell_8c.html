Description détaillée

Fichier contenant l'implémentation des fonctions utilisé par le shell pour le traitement et construction des commandes.

On y retrouve notament la fonction Shell_start() qui va démarrer le shell et l'intéraction avec l'utilisateur.

◆ Shell_add_var()

int Shell_add_var ( const char *  id_,
const char *  value_ 
)

Fonction qui va ajouter une variable dans la table des variables du shell.

Si la variable existe déjà dans la table, elle ne sera pas écrasée. La fonction va renvoyer 0. Pour écraser une variable déjà existante dans la table, utiliser plutôt Shell_update_var().

NB : Le liste des variables est détruite à la sortie du shell.

Paramètres
id_L'identificateur (nom) de la variable.
value_La valeur à stocker dans la variable.
Renvoie
1 Si l'ajout à réussi. 0 Sinon (La virable existe probablement dans la table).

◆ Shell_execute_all()

int Shell_execute_all ( ArrayList  struct_cmds)

Fonction qui va exécuter toutes les pipelines d'une commande structurée (par appel de la méthode execute() de chaque commande).

La fonction va créer un nouveau processus pour chaque éxécution de commande et va attendre que l'exécution de la commande soit terminée avant de passer à la commande suivante. La fonction s'occupera également de faire les redirections de sorties si jamais il y en a.

Paramètres
struct_cmdsLa commande structurée. Une commande structurée est une liste de listes
Renvoie
La valeur de retour de la dernière exécution (si elle échoue alors ce sera la valeur de son code d'erreur).

Création de deux tubes, entrant et sortant dont l'un (pipe1) sera celui qui remplacera stdin (tube entrant, en lecture) et l'autre (pipe2) remplacera stdout (tube sortant, en écriture).

On fait une copie des descripteurs de stdin et stdout actuels.

La copie est faite ici car stdin et stdout peuvent être redirigées avant l'exécution, Ex: pwd | for i in . {ftype $i|wc} | sort. Dans cet exemple lors de l'éxécution de {ftype $i|wc} stdin et stdout seront des tubes.

◆ Shell_get_val()

const char* Shell_get_val ( const char *  id_)

Fonction qui va renvoyer la valeur contenu dans une variable de la table des variables du shell.

Si la variable n'existe pas déjà dans la table la fonction va renvoyer NULL. Attention : La chaine de caractère renvoyée ne peut pas être modifiée, la copier si on souhaite l'utiliser.

NB : Le liste des variables est détruite à la sortie du shell.

Paramètres
id_L'identificateur (nom) de la variable.
Renvoie
La valeur stockée dans la variable. NULL sinon (la variable n'existe probablement pas dans la table).

Fonction qui va retirer une variable dans la table des variables du shell.

Si la variable n'existe pas déjà dans la table la fonction va renvoyer O. La fonction ne renvoie pas la valeur supprimée, utiliser Shell_get_val() si on souhaite la récupérer avant.

Paramètres
id_L'identificateur (nom) de la variable.
Renvoie
1 Si la suppression a réussi. 0 sinon (la variable n'existe probablement pas dans la table).
