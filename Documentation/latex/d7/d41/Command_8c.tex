Fonction qui va exécuter la commande. 

Cette fonction est abstraite (déclanche une erreur si aucune redéfinition n\textquotesingle{}est trouvée), à chaque appel la fonction va appeller la méthode {\ttfamily execute()} de l\textquotesingle{}objet (liason dynamique). Cela va permettre plus tard de créer une file de commandes toutes distinctes et de les éxécuter.

Classe de toutes les commandes. 

Il s\textquotesingle{}agit d\textquotesingle{}une classe abstraite qui représente une commande interne du shell. Elle possède une méthode abstraite à redéfinir dans tout sous-\/type de commande (sinon cela va déclancher une erreur), qui la méthode {\ttfamily execute()} appelée par {\ttfamily \mbox{\hyperlink{Command_8c_a67f00477620b6d9fce3659748d6e1eea}{Command\+\_\+execute()}}}, la fonction appelée pour exécuter la commande.
