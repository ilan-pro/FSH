Fichier contenant l\textquotesingle{}implémentation de la classe {\ttfamily \mbox{\hyperlink{struct__SimpleCmd__}{\+\_\+\+Simple\+Cmd\+\_\+}}}. 

Un objet de type {\ttfamily \mbox{\hyperlink{struct__SimpleCmd__}{\+\_\+\+Simple\+Cmd\+\_\+}}} est une commande dont les arguments et les paramètre sont récupéré directement (avec un parsing) dans le construteur. Ces commandes sont donc tous de la forme {\ttfamily Cmd\+\_\+name -\/param1 -\/param2 arg1 -\/parm3 ...}. Les arguments et les paramètres pouvant êtres déclarés dans un ordre quelconque et les paramètre peuvent être concaténés (Ex\+: {\ttfamily cmd -\/Ab\+Cd} = {\ttfamily cmd -\/A -\/b -\/C -\/d}). 

Cette classe ne fourni pas de méthode {\ttfamily execute()}, elle doit donc être héritée par une classe qui implémentera la méthode sinon l\textquotesingle{}exécution déclanchera une erreur. 

NB \+: Les commandes ayant une définition complexe comme les commandes avec des paramètres non-\/booléens (Ex \+: {\ttfamily cmd -\/-\/param=oiseau -\/param1 Wazo} ou {\ttfamily for i in ... \{\}} ).
