\doxysubsection{Description détaillée}
Classe des objets de type {\ttfamily Command\+Parse\+Handler\+Interpret}. 

Un objet Parse\+Handler\+Interpret est un objet qui possède un certain nombre de fonctions qui seront appelées par l\textquotesingle{}objet {\ttfamily \mbox{\hyperlink{struct__ParseHandler__}{\+\_\+\+Parse\+Handler\+\_\+}}} qui le contient, ces fonctions doivent définir les différentes actions à faire au moment de la rencontre de certains caractères spéciaux reconnu par l\textquotesingle{}objet {\ttfamily \mbox{\hyperlink{struct__ParseHandler__}{\+\_\+\+Parse\+Handler\+\_\+}}}.

Cette classe est un sous-\/type qui définie des fonctions pour gérer les caractères spéciaux des commandes du shell tels que \textquotesingle{};\textquotesingle{}, \textquotesingle{}$\vert$\textquotesingle{}, etc.

Cette classe a les méthodes public qui doivent toutes être redéfinies (mais ne déclanchent pas d\textquotesingle{}erreur si ce n\textquotesingle{}est pas le cas) elles ont une implémentation par défaut, qui d\textquotesingle{}accepte (ajoute le caractère au tampon du parser) tous les caractères spéciaux. Donc le mieux c\textquotesingle{}est de redéfinir celles dont on souhaite interpréter autrement.
