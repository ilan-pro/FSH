Ces commandes sont donc tous de la forme {\ttfamily Cmd\+\_\+name -\/param1 -\/param2 arg1 -\/parm3 ...}. Les arguments et les paramètres pouvant êtres déclarés dans un ordre quelconque et les paramètre peuvent être concaténés (Ex\+: {\ttfamily cmd -\/Ab\+Cd} = {\ttfamily cmd -\/A -\/b -\/C -\/d}). 

Cette classe ne fourni pas de méthode {\ttfamily execute()}, elle doit donc être héritée par une classe qui implémentera la méthode sinon l\textquotesingle{}exécution déclanchera une erreur.

Un caractère est valide si et seulement si \+:
\begin{DoxyItemize}
